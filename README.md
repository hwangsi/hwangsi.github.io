# Sungil Hwang — Project Catalog

Public project catalog: **https://hwangsi.github.io/**

A buildless, Korean-first directory of public GitHub repositories, with six featured projects, category and keyword filters, original/fork labels, upstream attribution, and direct links to web apps. The full card list is available without JavaScript.

## Edit the catalog

1. Edit `catalog/projects-curated.json` for titles, summaries, categories, featured order, and live links.
2. Update the public metadata snapshot in `catalog/meta-public.json` when adding repositories. Include public repositories only.
3. Run `python build_catalog.py` (Python 3, standard library only).
4. Commit the generated `index.html` and `projects.json`, along with any source changes. The generator also writes `catalog/profile-README.md` as a draft for the separate `hwangsi/hwangsi` profile repository; it does not push to that repository.

Metadata and counts are a snapshot, not an automatic live sync. Refresh the snapshot date and counts when changing the inventory.

## Files

- `index.html`: pre-rendered page, all project cards, metadata and accessible markup.
- `styles.css`: responsive layout, keyboard focus styles and reduced-motion support.
- `app.js`: client-side search, category/type filters, sorting, and shareable URL state. No external dependencies or API tokens.
- `projects.json`: readable generated project data.
- `assets/`: live-site preview captures and favicon. The HwangViewer demonstration is linked from its source repository.
- `catalog/`: curated descriptions and public GitHub metadata snapshot.

The existing `claim-desk/privacy/` page is retained separately and is not generated by this catalog.

## Attribution

Forks are labelled and link to their upstream repositories. Project previews show their respective existing public interfaces. Individual tools retain their own licenses and usage guidance.
