개인정보처리방침 — 청구 데스크 (Edge 확장)

시행일 2026-08-11 · 확장 버전 0.2.0 · English below

「청구 데스크」(이하 “본 확장”)는 분당서울대병원 연구관리시스템(MSRI, msri2.snubh.org)에서 연구비 지급신청의 영수증 기반 입력을 보조하는 개인용 도구입니다. 본 방침은 본 확장이 어떤 데이터를 다루는지 사실대로 밝히기 위한 것입니다.

1. 개발자가 수집하는 정보 — 없음

본 확장에는 개발자 서버가 존재하지 않습니다. 개발자는 이용자의 어떤 데이터도 수집·수신·저장·판매하지 않으며, 분석 도구·광고·추적 코드를 포함하지 않습니다. 원격 코드를 내려받아 실행하지 않고, 모든 코드는 설치 패키지에 동봉되어 있습니다.

2. 기기에만 저장되는 정보

아래 정보는 브라우저의 chrome.storage.local에 이용자 기기에만 저장되며 외부로 전송되지 않습니다. 기기·프로필 간에 동기화되지 않습니다.

과제 정보과제번호·과제명·유형 등 이용자가 등록하거나 화면에서 수집한 값
설정Anthropic API 키, 모델 선택, 동작 옵션
참석자 프리셋이용자가 저장한 회의 참석자 명단
처리 이력본 확장으로 수행한 입력 작업의 기록

또한 작업 중 생성되는 화면 캡처와 로그가 이용자의 다운로드 폴더(청구데스크/)에 저장됩니다. 이 파일들은 이용자의 컴퓨터에만 존재합니다.

3. 제3자에게 전송되는 정보 — 영수증 이미지(이용자가 실행할 때만)

본 확장의 영수증 판독 기능은 이용자가 해당 기능을 직접 실행한 경우에 한하여, 이용자가 선택한 영수증 이미지를 Anthropic PBC의 API(https://api.anthropic.com)로 전송하여 금액·상호·일자를 추출합니다. 이 전송에는 다음이 적용됩니다.

  • 전송은 이용자 본인이 입력한 Anthropic API 키로 이루어지며, 청구 주체도 이용자 본인입니다.
  • 전송 대상은 이용자가 선택한 영수증 파일과 추출 지시문뿐입니다. 계정 정보, MSRI 로그인 정보, 화면 캡처, 과제 정보는 전송하지 않습니다.
  • 개발자는 이 통신을 중계하지 않으며 그 내용에 접근할 수 없습니다.
  • 전송된 데이터의 처리는 Anthropic의 정책을 따릅니다: anthropic.com/legal/privacy
  • 판독 기능을 사용하지 않으면 본 확장은 어떤 외부 통신도 하지 않습니다. 영수증 이미지의 외부 전송을 원하지 않는 이용자는 이 기능을 쓰지 않고 값을 직접 입력할 수 있습니다.

영수증에는 카드번호 일부 등 민감할 수 있는 정보가 포함될 수 있으므로, 소속 기관의 정보보호 정책을 확인한 뒤 이 기능의 사용 여부를 판단하시기 바랍니다.

4. 로그인 정보

본 확장은 이용자의 아이디·비밀번호를 요구하거나, 입력하거나, 저장하지 않습니다. 이용자가 브라우저에서 이미 로그인한 세션 위에서 동작할 뿐이며, 로그인 화면에 값을 입력하는 동작은 코드 차원에서 차단되어 있습니다. 세션이 만료되면 작업을 중단하고 이용자에게 재로그인을 요청합니다.

6. 데이터 삭제

  • 로컬 저장 데이터: Edge에서 본 확장을 제거하면 함께 삭제됩니다. 패널의 설정에서 개별 삭제도 가능합니다.
  • 다운로드 폴더의 기록·캡처: 이용자가 직접 삭제합니다.
  • 개발자가 보관하는 데이터는 없으므로 개발자에게 삭제를 요청할 대상이 존재하지 않습니다.

7. 이용 대상

본 확장은 특정 기관의 내부 업무를 위한 도구이며 만 14세 미만 아동을 대상으로 하지 않습니다.

8. 변경 고지

본 방침이 변경되면 시행일과 함께 이 문서를 갱신하고, 변경이 데이터 처리 방식에 영향을 주는 경우 확장 업데이트 시 안내합니다.

Privacy Policy — Claim Desk (Edge extension)

Effective 2026-08-11 · Extension version 0.2.0

Claim Desk (“the extension”) is a personal productivity tool that assists with receipt-based expense entry in a hospital-internal research administration system (MSRI, msri2.snubh.org).

1. Information collected by the developer — none

There is no developer-operated server. The developer does not collect, receive, store, or sell any user data. The extension contains no analytics, advertising, or tracking code, and executes no remotely hosted code — all code ships inside the package.

2. Information stored on your device only

The following is stored in chrome.storage.local on your device only and is never transmitted. It does not sync across devices or profiles: project records (project number, name, type), settings (your Anthropic API key, model choice), saved meeting-attendee presets, and a history of entries made with the extension. Screenshots and logs produced during a run are saved to your Downloads folder (청구데스크/) and remain on your computer.

3. Information sent to a third party — receipt images, only when you invoke it

The optional receipt-reading feature sends the receipt image you select to the Anthropic API (https://api.anthropic.com) to extract the amount, merchant, and date — only when you invoke that feature. The request is made with your own Anthropic API key and is billed to you. Only the selected receipt file and the extraction prompt are sent; no credentials, no MSRI login data, no screenshots, and no project data. The developer does not proxy this request and cannot access its contents. Anthropic’s handling of the data is governed by anthropic.com/legal/privacy. If you do not use this feature, the extension makes no outbound network requests at all; you can type the values in manually instead. Receipts may contain sensitive details such as partial card numbers, so please check your organization’s information-security policy before using it.

4. Credentials

The extension never requests, enters, or stores your username or password. It operates on top of a session you have already signed into, and filling login fields is blocked at the code level. If the session expires, the extension stops and asks you to sign in again.

5. Why each permission is requested

debugger — the target application (SmartClient) contains widgets that respond only to trusted input events, so standard DOM manipulation cannot drive them; the permission is used only on tabs matching the host permissions below. host_permissions: msri2.snubh.org — the screen being automated. host_permissions: api.anthropic.com — the receipt reading in §3. storage — the local storage in §2. scripting, sidePanel — the side-panel UI and page-state checks. downloads — saving run records and screenshots to your Downloads folder.

6. Deleting your data

Removing the extension from Edge deletes its local storage; individual items can also be cleared from the panel’s settings. Files in your Downloads folder are deleted by you. The developer holds no data, so there is nothing to request deletion of.

7. Audience

The extension is a tool for internal work at a specific institution and is not directed to children under 14.

8. Changes

If this policy changes, this document is updated with a new effective date, and material changes to data handling are announced with the extension update.
